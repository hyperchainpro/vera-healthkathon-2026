## 🎭 Gaya & Prinsip Desain
- **Gaya Visual**: Modern, Bersih, Presisi Medis, Aksesibel.
- **Tipografi**: Inter / System Sans-Serif font dengan hierarchy kontras yang tegas.

## 🎨 Palet Warna
- **Primary / Brand**: Indigo (`#4F46E5` / `#6366F1`) - Memberikan kesan teknologi medis terpercaya.
- **Background**: Slate Light (`#F8FAFC`) / Card White (`#FFFFFF`).
- **Dark Mode**: Slate 900 (`#0F172A`) / Surface Slate 800 (`#1E293B`).
- **Status Warna Medis**:
  - Valid / Disetujui: Emerald 600 (`#059669`)
  - Dalam Tinjauan: Amber 500 (`#F59E0B`)
  - Dispute / Perlu Revisi: Orange 500 (`#F97316`)
  - Ditolak / Anomali Kritis: Rose 600 (`#E11D48`)

## 📱 Standar UX & Aksesibilitas
1. **Aksesibilitas (WCAG AA)**: Rasio kontras teks minimum 4.5:1 terhadap latar belakang.
2. **State UI Lengkap**: Setiap komponen data wajib memiliki:
   - Loading State (Skeleton shimmer)
   - Empty State (Ilustrasi & panduan tindakan)
   - Error State (Pesan ramah & tombol coba lagi)
3. **Responsivitas**: Tampilan adaptif sempurna pada layar mobile (375px), tablet (768px), dan desktop (1440px).
