# 🏛️ VERA Knowledge Vault & Second Brain (Obsidian Framework)

Selamat datang di knowledge base **VERA (Verifikasi Rawat Inap yang Efisien & Akuntabel)** - Healthkathon 2026.
Vault ini menggunakan standar **Obsidian Framework** dengan bidirectional wikilinks `[[...]]`, canvas, dan session memory tracking.
