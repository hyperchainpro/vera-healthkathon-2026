B02 · MASALAH UTAMA
Manipulasi Prolonged Stay — Hari Rawat Fiktif.
"Pasien masih lemah, perlu observasi lanjut."
— Frasa cukup ditulis di catatan medis untuk memperpanjang rawat inap. Sistem BPJS saat ini tidak bisa membuktikan sebaliknya.
01
Klaim normal diproses tanpa validasi biologis
BPJS membaca kode ICD & jumlah hari rawat. Catatan klinis tidak dianalisis secara temporal.
02
Satu kalimat narasi = perpanjangan sah
Dokter RS menulis justasi observasi — sistem terima sebagai valid. Tidak ada pembanding matematis.
03
Hari fiktif dibayar sebagai hari riil
Klaim H5-H7 untuk pasien Pneumonia yang lab-nya normal sejak H3 dibayar penuh. Kerugian terakumulasi diam-diam.
Anatomi Kasus — Pneumonia Fiktif H3→H7
Lab normal sejak H3, tapi klaim dipanjangkan sampai H7 → selisih 4 hari fiktif.

Ide Solusi
B03 · IDE SOLUSI
Mesin AI yang membuktikan kapan
pasien seharusnya pulang.
STEP 01
Extract
LLM Clinical NLP mengurai teks EMR tidak terstruktur → mengeluarkan parameter klinis harian: leukosit, trombosit, TD, suhu, kesadaran.
INPUT: "H3: TD 120/80, Lab: Leukosit 8000"
OUTPUT: {date:"H3", td_s:120, td_d:80, leuko:8000}
STEP 02
Compare
Logika Time-Series membandingkan kurva pasien dengan kurva pemulihan standar penyakit (Pneumonia, Stroke, CHF) berdasarkan sains medis.
deviation = ΣΔ (patient_curve, std_curve)
if deviation > threshold → flag
STEP 03
Flag
Jika Recovery Deviation Score melebihi ambang batas → picu Red Flag. Tampilkan grafik anomali sebagai bukti ilmiah untuk reviewer BPJS.
score=0.82 (HIGH)
STATUS: RED FLAG → REVIEW
Anatomi VERA
VERA bukan AI yang menggantikan reviewer manusia. VERA adalah mesin bukti ilmiah — ekstrak data biologis, bandingkan secara matematis, hadirkan anomali sebagai grafik. Reviewer BPJS memutuskan; VERA memberi bukti.

Contoh Prompt & JSON Output
B04 · STRICT PROMPTING + JSON SCHEMA
Bagaimana LLM mengubah teks EMR
menjadi data terstruktur.
⌥ PROMPT
// VERA strict extraction prompt
"Ekstrak tanggal, nilai leukosit, dan
nilai trombosit dari teks rekam medis ini.
Output HANYA format JSON
{date, leukosit, trombosit}.
Tidak ada teks lain. Jika nilai tidak
ditemukan, isi null. Jangan mengarang."
⌥ INPUT (teks EMR pasien)
"H3: Pasien sadar penuh, GCS 15.
TD 120/80, Nadi 78, Suhu 36.7°C.
Lab: Leukosit 8000, Trombosit 250.000.
Dokter: kondisi stabil, rencana observasi lanjut."
⌥ OUTPUT JSON (divalidasi)
{
  "date": "H3",
  "leukosit": 8000,
  "trombosit": 250000,
  "td_s": 120,
  "td_d": 80,
  "suhu": 36.7,
  "gcs": 15
}
Anti-Hallucination Layer
Output divalidasi dengan JSON Schema ketat di backend Vercel. Jika format tidak sesuai → retry dengan prompt klarifikasi. Jika masih gagal → field diisi null (TIDAK diinterpolasi). Tidak ada ruang untuk LLM mengarang angka lab.
Router strategy: OpenRouter/Xyrus memilih model termurah/tercepat untuk task ekstraksi sederhana. Biaya ~$0.0002/panggilan → skalabel untuk jutaan klaim/bulan.

VERA·Bagian 07
Penerima Manfaat
B07 · NILAI BAGI STAKEHOLDER
Tiga Pihak yang Diuntungkan,
Satu Sistem yang Melayani.
BPJS Kesehatan
PENJAGA INTEGRITAS JKN
Selamat dari defisit akibat fraud fiktif. Klaim rawat inap divalidasi biologis, integritas JKN terjaga. Setiap rupiah dibayar atas dasar bukti ilmiah, bukan narasi.
→ Penghematan ±Rp 300 M/tahun (estimasi)
RS Jujur
PERSAINGAN ADIL
Tidak dilindungi RS yang curang. Persaingan faskes jadi adil — yang jujur tidak kalah saham dengan yang manipulatif. Insentif untuk kualitas pelayanan, bukan strategi fraud.
→ Audit trail objektif sebagai pembela
Peserta JKN
TIDAK OVER-TREATMENT
Tidak dipertahankan rawat inap lebih lama dari indikasi medis. Hak pasien pulang tepat waktu dihormati. Risiko infeksi nosokomial & stres finansial berkurang. Kesehatan diutamakan.
→ Pulang tepat waktu, hak dihormati
Sistemik: Manfaat VERA menyebar ke seluruh ekosistem JKN — bukan hanya BPJS yang hemat. Setiap pihak yang jujur menang, hanya fraud yang kalah.

VERA·Bagian 08
Risiko, Privasi & Etika
B08 · MITIGASI RISIKO KRITIS
Tiga Risiko Utama,
Tiga Mitigasi Teknis & Etis.
#
RISIKO
MITIGASI
01
Kepatuhan UU PDP
Mengirim data PHI ke LLM pihak ketiga (OpenRouter/Xyrus) berpotensi melanggar UU PDP No. 27 Tahun 2022.
→ Data Stripping di Vercel Edge
Nama pasien, NIK, alamat dihapus/diganti mask sebelum data dikirim ke LLM. LLM hanya memproses teks medis murni (mis. "H3: TD 120/80, leukosit 8000"). Audit log hanya di Neon.
02
AI Hallucination
LLM berpotensi mengarang angka lab yang tidak ada di teks EMR asli → klaim fiktif divalidasi sebagai fiktif pula (false positive) atau sebaliknya.
→ JSON Schema Validation Ketat
Output LLM divalidasi skema JSON ketat di backend Vercel. Jika format tidak sesuai → retry. Jika masih gagal → field diisi null (TIDAK diinterpolasi). Tidak ada ruang mengarang.
03
False Positive (Tuduhan RS Jujur)
VERA salah flag RS yang jujur → tuduhan tidak berdasar, merusak hubungan BPJS-RS, sengketa hukum.
→ Human-in-the-Loop (Wajib)
VERA hanya memberi Red Flag + grafik bukti. Keputusan akhir tetap pada Reviewer Manusia. Skor 0.82 = prioritas review, bukan vonis. Reviewer bisa override dengan alasan medis.
Kepatuhan absolut: Tidak menggunakan data peserta JKN riil tanpa izin resmi dari pihak berwenang. Fase 1 (PoC) hanya memakai data sintetis MIMIC-IV turunan.
